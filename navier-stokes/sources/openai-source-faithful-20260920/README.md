# Finite Time Blowup for Navier–Stokes — editable transcription

[Read the 166-page PDF](upstream/output/pdf/source-faithful-reconstruction.pdf) · [Browse the LaTeX](upstream/reconstruction/) · [Download the source package](full-source-release.zip) · [Read OpenAI’s original paper](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf)

This collection provides an independent LaTeX transcription of OpenAI’s *Finite Time Blowup for Navier–Stokes*: its main text, appendices and bibliography, 29 section files, style, six figure assets and reading PDF. The [source repository](https://github.com/KokunoYumeto/openai-navier-stokes-latex) provides the same section text. The transcription aims to retain OpenAI’s wording and mathematics; mathematical commentary and proposed mathematical corrections are separate from it.

Full fidelity of this transcription has not been established. The [source-comparison status](upstream/evidence/transcription/TRANSCRIPTION_AUDIT.json) specifies the formulas and symbols actually checked against original pages. The [document-build record](upstream/evidence/build/CURRENT_DOCUMENT.json) identifies the PDF and the rendered pages inspected. These are limited transcription and layout checks, not validation of the theorem.

The ZIP contains the editable document inputs, figure assets, reading PDF, rights notice, reading guide, current indexes and their manifest. The [package manifest](PACKAGE_MANIFEST.sha256) lists those files exactly. Supporting repository records remain available outside the ZIP. Run `python verify_mirror.py` to compare the archive with the listed files under `upstream/`.

Build instructions and source citations are in the [reading guide](upstream/README.md). The [166-page source-edition archive](https://doi.org/10.5281/zenodo.22852310) and [its publication family](https://doi.org/10.5281/zenodo.22852309) are available separately. The [208-page analytical reader](../../navier_stokes_workbench_208p.pdf) is a different work.
