## Confirmed defects and required repairs

1. **Nested-package occurrence model.**  The first catalogue expands each distinct nested ZIP byte sequence once and records repeated encounters only as a counter.  It therefore does not identify every archive/member occurrence of every nested package, and its count of 12,822 nested members cannot be described as a count of all logical occurrences.  A versioned catalogue must represent package byte versions, package members, containment edges, and each direct package occurrence separately.
2. **Verification scope.**  The first verification receipt counts repeated numerical samples as separate checks and does not independently test several exact identities.  Its tomography example is diagonal and therefore does not test recovery of off-diagonal covariance entries.  A replacement audit must classify exact symbolic checks separately from numerical checks and test a non-diagonal positive-definite covariance.
3. **Tomography underclaim and first repair rejected.**  R7 uses 78 separate two-level experiments.  An initial repair grouped those data into one 13-level channel, but that still treated the covariance as an unrestricted symmetric $12\times12$ matrix.  The correct parameter is $H^{-1}\in\operatorname{Herm}_3(\mathbb H)$, which has fifteen real dimensions.  The final repair gives one six-level channel with fifteen pair magnitudes and an exact measurement determinant $-2^{12}$.  The observation-only parameter lies in $\operatorname{Herm}_2(\mathbb H)$, has six dimensions, and is recovered by one four-level channel with determinant $-2^4$.  Kernel perturbations prove both scalar-data lower bounds, and pair counts prove both level lower bounds.
4. **Brownian construction and dimensions.**  R6 gives the desired covariance but does not define the integrated Gaussian phase variable separately from the static parameter.  The repaired statement must introduce $Y_\tau$ with covariance $\tau_c\tau\Sigma_H$, state its units, define its diagonal unitary channel, and prove the convolution and semigroup laws.
5. **Terminology.**  The R2 equality family is an equality family for data processing under the projection map.  Reader text and figures must use that exact description so it cannot be confused with vanishing relative entropy.
6. **Transcription defects.**  The claim ledger contains malformed LaTeX control words in MC-002 and MC-005.  All authored Markdown and TeX must be scanned for comparable defects.
7. **Stale receipts.**  Any edit to a hashed artifact invalidates the existing consolidation receipt.  The final receipt must be regenerated from the corrected artifacts and must identify the superseded receipts.
8. **Direct-member hash collision in V1.**  The mutable V1 key $(\text{archive hash},\text{member name})$ allowed a nested 4,078-byte `MANIFEST.json` to overwrite the binding for a later 52,910,440-byte direct file.  V2.1 checks all 41,695 direct text mappings against central-directory byte counts and CRC32 values and rehashes every mismatch from the outer archive.  The corrected direct SHA-256 is `cc0bc89d33fd580a51a1239ba7a9c875098b43dbc327d33bdbc14312dae16b0d`.
9. **Residual endpoint completeness.**  The last theorem-level pass found that R8 did not explicitly state the unnormalized moment on the empty positive locus.  The corrected theorem records $J_p=0$ and an undefined conditional moment for $m\le-\beta$; R3 now restricts its conditional-finiteness equivalence to orbits with nonempty positive part.
